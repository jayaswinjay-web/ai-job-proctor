# Voice data provenance

India's DPDP Act 2023: collect minimum data, obtain consent, support access and deletion,
redact PII from logs, store data in an Indian region.

Rules:
- Only voice data licensed or recorded with signed consent from the speaker.
- Never clone a real person's voice (including public figures) without written permission.
- Document provenance per speaker here when voices are recorded / fine-tuned.
- Add audio watermarking or clear synthetic-speech disclosure (prompt section 8).
